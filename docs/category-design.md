# CampusTrade カテゴリ設計書

## 1. 目的

本書は、CampusTrade における商品カテゴリの分類体系を定義する。学内フリーマーケットで出品される主なジャンルを、検索・絞り込み・出品時の選択肢として利用する。

## 2. 分類方針

- カテゴリは **大分類（100番台）** と **小分類（110番台以降）** の2階層で構成する。
- 数値IDは大分類100刻み、小分類は大分類内で10刻みとし、将来の追加に備えて番号に余白を設ける。
- 商品出品時は **小分類** を選択する。検索・一覧では大分類または小分類で絞り込めるようにする。

## 5. 関連設計との関係

- 商品の `category_id` には **小分類ID**（110, 120, …）を保存する。
- 大分類は検索UIやナビゲーション用のグルーピングとして扱い、DB上は小分類IDの桁（100の位）から導出するか、別テーブルで管理する。
- 基本設計書・DB設計書に記載の旧カテゴリ例（教科書、参考書、文房具、電化製品、生活用品、その他）は、本書の分類体系に置き換える。
