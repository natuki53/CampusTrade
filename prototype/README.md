# CampusTrade UIプロトタイプ

CampusTrade の静的UIプロトタイプです。HTML、CSS、JavaScript のみで構成し、Spring Boot + Thymeleaf に移植しやすい画面構造にしています。

## ファイル

- `index.html`: 画面構造
- `styles.css`: レイアウト、配色、レスポンシブ対応
- `app.js`: 画面切り替え、商品詳細の状態切り替え、出品プレビュー

## 含まれる画面

- トップ画面
- 商品検索結果画面
- 商品詳細画面
- 商品出品画面
- マイページ
- 管理者ダッシュボード
- ログイン・会員登録画面

## 確認方法

`index.html` をブラウザで開きます。
