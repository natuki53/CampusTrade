## 前提

CampusTrade は、学内で教科書、参考書、生活用品などを学生同士で譲渡・売買するためのフリーマーケットシステムです。

主要な利用者は以下の2種類です。

- 一般学生: 商品の出品、購入申し込み、取引調整を行う。
- 管理者: 不適切な出品の監視、カテゴリ管理、出品の非表示を行う。
